## The Multi-Site Challenge

A protocol that works well in one location doesn't automatically transfer to a second or third. Different staff, different equipment, and different physical spaces all introduce variables.

## What Standardization Actually Requires

Standardization isn't about writing one document and distributing it. It's about ensuring the protocol runs the same way in every location, with the same training standards and the same documentation.

- Equipment specifications must be consistent across sites
- Staff competency training must be equivalent, not just similar
- Documentation and audit schedules must run independently at each location

## Common Failure Points

The most common failure in multi-site standardization is assuming that trained staff at one location can train staff at another. Each site needs its own competency verification tied to the same standard.

## Takeaways

Multi-site standardization requires independent verification at each location against a single standard. Distribution is not the same as implementation.
